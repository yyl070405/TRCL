# TRCL 路线图：全能为目标

“全能”不是功能堆砌，而是**别人能启动的版本、账号、内容、平台，我们都能覆盖，且有一致的体验**。

## 里程碑

- [x] ARM64 原生库自动替换
- [ ] Quilt / NeoForge 真机验证
- [ ] OptiFine、LiteLoader
- [ ] CurseForge 整合包（API key）

### M2 内容管理闭环

- [ ] 模组更新检查与一键升级
- [ ] 依赖冲突/缺失提示
- [ ] 实例导入导出（zip）、备份

### M3 Android 真正可玩

- [ ] runtime pack（JRE 21/25 + LWJGL patch + MobileGlues）由 CI 构建
- [ ] APK 接入运行时与启动桥
- [ ] 触屏 HUD 原生化（不依赖 xdotool）

### M4 账号与生态

- [ ] authlib-injector 外置登录
- [ ] 自动更新（latest.json + 签名）
- [ ] 插件 API
- [ ] 远程管理（可选，自建域名）

## 优先级判断

1. **Android runtime pack**：决定“全能”是否包含手机，且已有全部素材（FCL APK 内含 JRE/LWJGL）
2. **CurseForge + OptiFine**：决定内容覆盖面
3. **实例导入导出/更新**：决定日常可用性
4. **自动更新/插件**：决定长期生态

## 不做的事

- 不做联机大厅、服务器托管（与启动器定位无关）
- 不做盗版账号破解、皮肤站盗链
- 不把游戏文件打进安装包
